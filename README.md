# 🐾 PetVida - Plataforma Web para Pet Shop

## 📖 Sobre o Projeto

O **PetVida** é um projeto de desenvolvimento web criado com o objetivo de oferecer uma experiência moderna, intuitiva e acolhedora para tutores de animais. O projeto foi desenvolvido visando simular um sistema real de um pet shop, priorizando usabilidade, identidade visual e organização das informações.

O site foi pensado para transmitir confiança, carinho e profissionalismo, utilizando uma interface amigável e responsiva.

---

## 📱 Responsividade

O projeto foi adaptado para diferentes dispositivos, proporcionando uma experiência consistente tanto em desktops quanto em dispositivos móveis.

### 🖥️ Desktop
- Layout em múltiplas colunas;
- Melhor aproveitamento da largura da tela;
- Organização visual voltada para telas maiores.

### 📱 Mobile
- Reorganização das seções;
- Cards empilhados verticalmente;
- Botões em largura total;
- Menu adaptado;
- Melhor experiência em dispositivos móveis.

## 🚀 Processo de Desenvolvimento

### 1. Planejamento
Definição da estrutura do sistema e estudo de referências visuais.

### 2. Wireframes
Criação de protótipos de baixa fidelidade para as páginas:

- Home;
- Sobre Nós;
- Serviços;
- Trabalhe Conosco;
- Entrar/Cadastrar.

### 3. Protótipos Visuais
Desenvolvimento de layouts de alta fidelidade com:

- Imagens personalizadas;
- Ícones;
- Componentes reutilizáveis.

### 4. Implementação
Construção da interface utilizando:

- HTML5;
- CSS3;
- JavaScript.

### 5. Ajustes Finais
- Responsividade;
- Efeitos de hover nos botões;
- Espaçamentos;
- Organização visual;
- Refinamento da experiência do usuário.
